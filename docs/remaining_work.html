The order things must happen in

Two rules decide the whole schedule.

  • Nothing is benchmarked before the freeze commit. The golden set and the prediction record must be in git before any model sees a golden ticket and before any JMeter run. The commit history is the evidence, and breaking the order costs the whole measurement component.
  • Only one test runs on Machine A at a time. Accuracy, load and stress tests all use Irfan's CPU. Running two at once corrupts both, so the order is accuracy, then load, then stress.
